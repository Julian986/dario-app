# Ámbito

Idea inicial de un sistema online para documentación ambiental.

```bash
npm run dev
```

Abrí [http://localhost:8464](http://localhost:8464).

- `/` — landing
- `/idea` — Idea (concepto + boceto)
- `/conversacion` — Conversación (ida y vuelta; copiar y responder por WhatsApp)
- `/app` — Aplicación (prototipo en vivo que evoluciona)
